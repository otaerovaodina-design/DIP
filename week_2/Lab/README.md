# LAB2 - Image Arithmetic Operations

## Overview
Exploration of basic arithmetic operations on images using OpenCV, including brightness and contrast adjustments.

## Topics Covered
- Image addition (brightness increase)
- Image subtraction (brightness decrease)
- Image multiplication (contrast increase)
- Image division (contrast decrease)
- Visual comparison of original vs. modified images

## Key Functions
- `cv2.add()` - Add constant to image
- `cv2.subtract()` - Subtract constant from image
- `cv2.multiply()` - Multiply image by constant
- `cv2.divide()` - Divide image by constant

## Files
- `main.ipynb` - Jupyter notebook with all exercises
- `flower.jpg` - Sample image used for operations
