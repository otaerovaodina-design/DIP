# LAB1 - Basic Image Processing

## Overview
Introduction to fundamental OpenCV operations for image loading, manipulation, and analysis.

## Topics Covered
- Loading and displaying images with OpenCV
- Image properties: dimensions (2496x3840), channels (3), data type (uint8), total pixels
- Image copying and modification
- Drawing shapes (rectangles) on images
- Grayscale conversion
- Binary thresholding

## Key Functions
- `cv2.imread()` - Load images
- `cv2.cvtColor()` - Color space conversion
- `cv2.rectangle()` - Draw rectangles
- `cv2.imwrite()` - Save images
- `cv2.threshold()` - Binary thresholding

## Files
- `main.ipynb` - Jupyter notebook with all exercises
- `car.jpg` - Sample image used for processing
