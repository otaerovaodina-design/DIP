# LAB4 - Image Processing

Some basic image processing stuff I did for my CV class. 

Open main.ipynb in jupyter and run the cells.

Make sure you have the required libraries installed (numpy, opencv-python, matplotlib).

The notebook loads an image called mesi.jpg and shows a bunch of different transformations - gamma correction, contrast stretching, flipping, negative, intensity range stuff, and bit plane slicing. 

There's also a corrected version saved as mesi_gamma_corrected.jpg.

That's pretty much it honestly.
